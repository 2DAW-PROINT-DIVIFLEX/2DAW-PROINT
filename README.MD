# DiviFlex

## ¿Qué es DiviFlex?

DiviFlex es una aplicación web full-stack diseñada para simplificar y hacer más justa la gestión de gastos compartidos.
A diferencia de otras alternativas en el mercado, DiviFlex ofrece un sistema híbrido de reparto que permite tanto la división clásica a partes iguales como la asignación de gastos individuales y asimétricos, ajustándose al consumo real de cada persona.

Ideal para viajes, pisos compartidos y eventos, la plataforma permite crear grupos de hasta 50 participantes, establecer fechas límite para grupos temporales y generar estadísticas gráficas e interactivas para visualizar fácilmente los balances y las deudas.

## Tecnologías

Este proyecto está desarrollado utilizando una arquitectura desacoplada (Frontend/Backend) y se apoya en las siguientes tecnologías:

### Frontend

Framework: Angular (con TypeScript)

Estilos y UI: Tailwind CSS y Bootstrap

###Backend

Lenguaje: PHP

Framework: Laravel (REST API)

Autenticación: JWT (JSON Web Tokens) y Laravel Socialite (OAuth 2.0 para login social)

###Base de Datos

Sistema Gestor: PostgreSQL

### Infraestructura y Despliegue

Contenedores: Docker & Docker Compose

Servidor Web: Apache

Seguridad: Certificado SSL (Let's Encrypt) / HTTPS
